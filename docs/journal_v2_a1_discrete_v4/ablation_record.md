# Development ablation record — learned A1 tactical interface (journal V2)

All four designs share the frozen canonical V2 environment, the frozen common obstacle layer, canonical A0 (`journal-v2-a0-canonical-v1`), the 37-D observation and the PPO hyper-parameters. Matched evaluation reference: A0 capture 10.4% (seeds 140000–140099).

All three seeds converged to the same policy: turn ≈ 145° away from the asset, climb to the ceiling, hover. | Capture **0 / 6,000** (A0 10.4%). ## Cross-cutting findings usable in the dissertation/journal
1. **Delayed failure under discounting** (v1): with γ = 0.99 a failure 800+ steps away is worth ≈ 0; the compensating step cost −(1 − γ)·R_F = −0.1 makes surviving forever worth exactly one failure (offline-verified).
2. **Authority is not safety** (v2) and **per-command safety is not recoverability** (v3): both are properties of the *closed loop* with the frozen obstacle layer.
3. **The benchmark's A0 is collision-free by construction** (0 collisions in every matched stress cell), so "no gained collisions" is a demanding but well-defined criterion for any learned tactical layer.
4. **Defender-driven tactical behavior is absent from the V2 attacker by design** (`direct_obstacle_only`, evasion zeroed). Any learned A1 that claims evasion authority must therefore *introduce* the maneuver geometry; it cannot be assembled from the obstacle-navigation primitives.
