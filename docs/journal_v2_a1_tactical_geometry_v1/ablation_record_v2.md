## Cross-cutting findings
1. Delayed failure under discounting (design 1) is fixed by reward v2 (offline-verified); reward v2 is unchanged through design 5.
2. Authority ≠ safety (designs 2, 5); per-command safety ≠ recoverability (design 3). Designs 2, 3 and 5 fail for the same underlying reason: the frozen common layer is a *reactive* controller whose own trigger (direct rollout) cannot protect against states it was never designed to be handed.
3. Canonical A0 is collision-free by construction in every matched stress cell, so "no gained collisions" is demanding but well defined.
4. A defender-evasion action space is scientifically meaningful (design 5: the pulses change defender-relevant outcomes in both directions, net positive for θ ≥ 15°), so the open problem is *safe* execution, not whether evasion authority exists.
